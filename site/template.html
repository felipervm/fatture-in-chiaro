Le fatture elettroniche
raccontano già come va l’azienda.

I gestionali italiani producono le fatture elettroniche in XML. Ho scritto uno strumento in Python che le legge, controlla che siano corrette e ne ricava un riepilogo commerciale. Qui lo provo su un anno di fatture di una cantina inventata.

Dati dimostrativi: azienda, clienti e prodotti sono inventati. Il formato dei file è quello ufficiale (FatturaPA 1.2.1).

Prima dei numeri

Controllare le fatture prima di usarle

Ogni file viene confrontato con lo schema ufficiale dell’Agenzia delle Entrate. Poi controllo quello che lo schema non vede: file inviati due volte, totali che non tornano, note di credito senza la fattura a cui si riferiscono.

Andamento

Fatturato netto mese per mese

Imponibile delle fatture meno le note di credito, senza IVA. I file esclusi dai controlli non sono contati.

Clienti

Clienti da sentire

Clienti abituali che non ricevono una fattura da molto più del loro ritmo normale. È una domanda per il commerciale, non la prova di un cliente perso.

Come funziona

Dalla cartella di XML al riepilogo, con un comando

1 · LeggereLegge tutti i file XML di una cartella, anche quelli con più fatture dentro.
2 · ControllareSchema ufficiale, duplicati, numeri ripetuti, totali e note di credito.
3 · SalvareCarica documenti, righe e controlli in un database SQLite, interrogabile con SQL.
4 · RiassumereGenera questa pagina. Ogni totale torna con la somma delle fatture.
  • Provato sui file ufficiali. Oltre alle fatture dimostrative, lo strumento legge i file di esempio pubblicati per la FatturaPA (FPR01, FPR02, FPR03).
  • Problemi inseriti apposta. Nelle fatture dimostrative ho inserito problemi per verificare che i controlli li trovino: li trovano tutti. Una differenza di 1 centesimo, invece, è considerata un arrotondamento e non viene segnalata.
  • Test automatici. Riconciliazione dei totali (mesi, clienti e prodotti danno lo stesso netto), lettura dei file ufficiali, problemi trovati.
  • Strumenti: Python, lxml, SQLite, pytest. Il codice è su GitHub.
